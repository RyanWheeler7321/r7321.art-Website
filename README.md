# r7321.art

This is the source for [r7321.art](https://r7321.art), my site for games, tools, updates, and whatever else I am making.

It is an Eleventy static site. A small media pipeline turns the original images and GIFs into WebP images in a few sizes and short MP4 loops, so pages load faster. It runs on Cloudflare, and the message form sends feedback and bug reports through a small Worker in `worker`.
