I've started working on another game project: *bithunters*. Alongside *NIGHTSWEEPER*, I'm challenging myself to develop and release two full games at the same time.

I first showed *bithunters* as a multiplayer 2D action game where up to four players controlled personified computer programs. I've transformed that old idea into a single-player turn-based adventure. I'm going for a more dynamic turn-based gameplay system, with incremental mechanics that build over the course of the game and a thematic storyline running through it.

{% image "/images/updates/new-project-bithunters/bithunters-hq.png", "The bithunters party exploring its headquarters through a damaged arcade display." %}

The whole game is presented through a damaged arcade machine, with a modern, distorted retro style built around strong colors, shifting palettes, and vector art. It isn't quite pixel art, but I still want it to carry the clarity and feeling of an older game.

{% image "/images/updates/new-project-bithunters/bithunters-loadout.png", "bithunters party loadout screen shown in its strong magenta palette." %}

The Steam pages for both games are finished and currently awaiting review. Right now I'm developing the demos. If I can get those small, complete versions working the way I want, I think they'll give me enough of each game's foundation to proceed with the rest of development. Quality is the priority over quantity, but we'll see quickly how this goes...
