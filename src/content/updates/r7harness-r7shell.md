AI models have gotten really good this year. I use Codex and Claude pretty much every day, and I wanted a harness and terminal I can customize however I want, so I made both.

r7Harness is my agent harness, built on OMP. It has task titles with time estimates, separate profiles for each agent, and a reply style with colored markers for key points, finished work and questions.

r7Shell is a lean custom terminal for Windows, made for running agents in WSL, as well as anything else you'd run in a terminal. Sessions keep running in the background, new text fades in and moved text glides into place, and a window flashes when its agent finishes a response.

{% image "/images/updates/r7harness-r7shell/r7harness-r7shell-01.png", "r7Harness in r7Shell, showing a finished reply with colored markers." %}

Running r7Harness in r7Shell, you also get pictures inside replies, bigger titles and mouse editing in the input box.

{% image "/images/updates/r7harness-r7shell/r7harness-r7shell-02.png", "An agent working in one r7Shell window, next to the launch screen in another." %}
